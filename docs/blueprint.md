# **App Name**: OfflineExamPro

## Core Features:

- Teacher Authentication: Secure teacher login and signup using localStorage.
- Student Authentication: Secure student login and signup using localStorage.
- Test Creation: Create and manage tests with various question types (MCQ, short answer, essay) and define parameters such as duration and access.
- Test Taking: Allow students to take tests within the defined time limit, with auto-submission upon timeout.
- Automated Grading: Automatically grade MCQ questions.
- Report Generation: Generate detailed student performance reports and batch leaderboards, storing data locally.

## Style Guidelines:

- Primary color: Deep Purple (#5B2A86) for a professional and modern feel.
- Background color: Deep Blue (#1B1B3A) with low saturation, offering a dark, readable backdrop.
- Accent color: Teal (#00C9A7) for interactive elements and highlights, creating a vibrant contrast.
- Headline font: 'Poppins', a sans-serif for headings and titles, giving a modern, clean aesthetic.
- Body font: 'PT Sans', a versatile sans-serif, making paragraphs easily readable.
- Subtle animated gradient background blending deep blue, purple, and teal tones.
- Cards and sections use semi-transparent panels over the animated background.
- Simple, clear icons to represent different actions and question types.
